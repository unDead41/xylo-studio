# Spesifikasi aliran branch

Diluluskan oleh Ijamm dalam chat pada 2 November 2026.

Repo: `unDead41/xylo-studio`. Branch dan pemilikan: `docs/BRANCH_POLICY.md`.

Satu repo kendiri untuk alat muzik dan permainan HTML digital. Semua perubahan sedia ada yang relevan diselamatkan sebelum pembersihan branch. Sejarah Git tidak ditulis semula. Pemilikan main dan arahan kemas kini manual dihormati.

Pendekatan dipilih: branch kekal mengikut peranan, audit sebagai penyelaras, share sebagai snapshot agihan. Satu branch pembangunan umum tanpa pemisahan tugas tidak memenuhi kehendak chat khusus pengguna. Share automatik tidak dipilih kerana pengguna mengawal masa agihan.

Kriteria siap: senarai branch tepat, sumber/ujian sesuai repo, versi dan SOR semasa, pakej share yang boleh diekstrak, semakan bebas serta SHA remote disahkan.
