# Mula menggunakan Xylo Studio

Muat turun ZIP branch share, extract dan buka index.html dalam Chrome/Edge. Klik atau tekan bar untuk mengaktifkan audio. Gunakan Studio untuk lagu/rakaman, atau Permainan untuk permainan rentak. Tiada Node.js diperlukan untuk bermain.

Mikrofon ialah pilihan dan memerlukan HTTPS atau localhost. Untuk server setempat jika Python tersedia: `python -m http.server 8000`, kemudian buka http://localhost:8000. Muat turun JSON bagi sandaran rakaman; simpanan pelayar adalah khusus peranti/origin. Tiada raw audio disimpan atau dihantar.

Kata laluan eksport setempat: demo41 atau demo@41. Eksport JSON/CSV tersedia. Panduan penuh source pada main; snapshot share hanya berubah apabila diminta.
